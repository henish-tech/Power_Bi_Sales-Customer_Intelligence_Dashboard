# Power_Bi_Sales-Customer_Intelligence_Dashboard
This Power BI project is designed to analyze sales performance, customer behavior, product trends, and regional business insights using interactive dashboards and reports.


The project uses Excel data sources with multiple tables including Customer_Dim, Product_Dim, Product_Dim, Date_Dim, Sales_Fact, Returns_Fact, and Region_Dim to create a complete star schema model.

## Key Features

* Data Modeling using Star Schema
* DAX Measures and Calculated Columns
* KPI Cards for Total Sales, Returns, Average Sales, and YTD Sales
* Time Intelligence Measures (YOY, YTD)
* Top 5 Products Analysis
* Region-wise Sales Map
* Customer Segment Analysis
* Drillthrough Page for Customer Details
* Tooltip Page for Quick Insights
* Interactive Slicers and Filters
* Mobile Layout Optimization
* Role Level Security (RLS)
* Professional Executive Dashboard Design

## Tools Used

* Power BI Desktop
* Microsoft Excel
* DAX (Data Analysis Expressions)
* Data Modeling Techniques

## Project Outcome

This dashboard helps in better business decision-making by providing clear insights into customer performance, product sales, returns analysis, and regional growth opportunities through powerful visualizations and reports.
